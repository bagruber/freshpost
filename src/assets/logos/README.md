# Logo-Varianten

SVG-Dateien des fresh-Logos hier ablegen — die App findet sie automatisch
(Dev-Server bzw. Build neu starten). Erscheint dann als Logo-Picker in den
Controls; ohne Dateien bleibt der Picker ausgeblendet.

- **Nur SVG.** Weiß-Varianten für dunkle Hintergründe, Akzent-Varianten nach CI.
- **Dateiname = Anzeigename** im Picker: `fresh-weiss.svg` → „fresh weiss".
- Die Logos werden unverändert gerendert (kein Recolor) — Farben müssen also
  schon im SVG stimmen.
